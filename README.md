# Shawn Leyson Portfolio

A responsive, static portfolio for mechanical engineering technology student Shawn Leyson. It highlights his education, manufacturing experience, robotics leadership, technical skills, and selected engineering projects.

## View the site

Open `index.html` directly in a browser. The site uses relative links and works without a build step or external services. To publish it, configure GitHub Pages to deploy the repository root from the `main` branch. The live-site URL can be added here after Pages is enabled and verified.

## Editing and rearranging content

Each page is plain HTML, and each section is marked with a `MOVEABLE SECTION` comment. Move a whole `<section>` block to a different position or page to change where content appears. Project cards and project details are in `projects.html`; skill categories are in `skills.html`; the shared colors and responsive layout are in `styles.css`. `CONTENT-GUIDE.md` has a quick editing map.

## Notes

- Built with HTML5, CSS3, and small vanilla JavaScript enhancements.
- Project photographs, CAD views, and a CAM toolpath image are extracted from the supplied engineering portfolio and stored locally in `assets/`.
- The Contact page links to LinkedIn. The site has no backend and does not collect messages.
- Portfolio facts and project descriptions are based on the resume and engineering portfolio supplied by Shawn Leyson. Graduation timing was left open where the source was unclear.
